# astrbot_plugin_dsh_bridge

把 QQ 变成 **DeepSeek Harness（DSH）** 的远程入口：手机上发一句话，电脑上的 DSH 就帮你干活，结果以简报和文件的形式回到 QQ。

```
手机 QQ ──► 机器人 ──► AstrBot ──► 本机 dsh headless ──► 你的电脑
   ▲                                        │
   └────────── 简报（≤400 字）+ 产物文件 ◄────┘
```

## 特性

- **手机远程派活**：QQ 里发 `/dsh 任务`，DSH 在本机执行
- **多段收集**：任务可分几条消息说，`/dsh send` 才提交，期间机器人不插嘴
- **收附件**：文件/图片发给机器人，DSH 能读到本地路径
- **回产物**：生成的文件自动作为 QQ 文件消息发回
- **权限分档**：私聊 只读/工作区写/完全访问；群聊最高工作区写，管理员可一次性提权
- **会话复用**：连续任务共享上下文，带 TTL；群聊可选「全群共用」或「每人独立」
- **UMO 白名单**：与 AstrBot 访问控制同一套写法（`平台:FriendMessage:QQ`）
- **零手改配置**：全部在 AstrBot 后台用表单填写，DSH profile 自动创建

## 环境要求

| 组件 | 要求 |
|---|---|
| AstrBot | ≥ 4.29.0 |
| DeepSeek Harness | ≥ 0.2.1-rc.3，能运行 `dsh headless` |
| NapCat / OneBot v11 | 4.x（AstrBot 的 aiocqhttp 适配器） |
| 操作系统 | Windows（当前仅实测 Windows） |
| 模型密钥 | 自动读取 AstrBot 里已配置的 DeepSeek provider |

## 三步配置

| 步骤 | 操作 |
|---|---|
| 1. 拿会话 ID | 私聊机器人发 `/sid`，得到类似 `肥嘟嘟:FriendMessage:2809688590` |
| 2. 加白名单 | 后台 → 插件 → 配置 → 「💬 私聊 · 私聊白名单」加一行；同一行也加到「👑 管理员 · 管理员名单」 |
| 3. 验证 | QQ 里发 `/dsh status`，能看到「身份：管理员」就通了 |

> DSH 侧 `bot` / `bot-ro` / `bot-full` 三个 profile 由插件首次启动自动生成并校验。

## 命令

| 输入 | 谁能用 | 含义 |
|---|---|---|
| `/dsh 内容` | 白名单 | 开始任务（可带第一段） |
| 直接发消息 / 文件 | 白名单 | 追加片段或附件（期间**不回复**） |
| `/dsh send` | 白名单 | 提交执行 |
| `/dsh cancel` | 白名单 | 取消收集 |
| `/dsh status` | 白名单 | 会话、身份、权限、上下文 |
| `/dsh doctor` | 白名单 | 环境自检 |
| `/dsh perm [ro\|ws\|full]` | 见下 | 查看/切换权限 |
| `/dsh reset` | 管理员 | 清空本会话 DSH 记忆 |
| `/dsh init` | 管理员 | 补建缺失 profile |
| `/dsh set <键> <值> confirm` | 管理员 | 改白名单/默认权限/文件上限 |
| `/dsh help` | 白名单 | 用法 |

## 权限规则

| 身份 | 私聊 | 群聊 |
|---|---|---|
| 管理员 | 可切到 **完全访问**（持久） | 持久最高 **工作区写**；可申请 **一次性完全访问**（仅下一条自己发起的任务） |
| 普通白名单 | 最高 **工作区写** | 不能切权限 |
| 群成员 | — | 不能切权限，只能执行任务 |

- `/dsh perm full` 一律需要再发一次 `confirm`
- 群里的一次性提权 10 分钟不用会自动失效

## 群聊上下文（两个列表兼群白名单）

| 列表 | 效果 |
|---|---|
| 共用一个上下文的群 | 该群所有发言者共用一个 DSH 会话 |
| 每人独立上下文的群 | 每个发言者各用一个会话，互不串台 |
| 两个都没有 | 完全不响应 |
| 同时出现 | 按「共用」处理，并提示 |

获取群会话 ID：在群里 @机器人 发 `/sid`。

## 常见问题

| 现象 | 处理 |
|---|---|
| `/dsh` 没反应 | 检查 `private_whitelist` / `group_shared_context` 是否加了对应 UMO；群里要开「允许群聊」并 @ |
| 发了消息机器人不理人 | 可能在收集状态：`/dsh cancel` |
| 提示找不到 CLI | 配置里填 `dsh_cli_path` 完整路径 |
| 文件没回传 | `files` 需在工作区内、不超过「回传文件上限」；看日志 `回传文件：N 个` |
| 权限切不动 | 普通用户最高 ws；full 仅管理员；群里只有管理员能切 |
| 和 AstrBot 白名单冲突 | AstrBot「访问控制」白名单与插件白名单**两处都要加** |

## 实现要点

- 任务通过 **stdin** 传给 `dsh`，避免 Windows 批处理在换行处截断
- 解析 `dsh --json` 事件流，取 `final` 文本与会话 id
- 会话按 `(会话, 权限)` 隔离，避免切权限时沙箱状态串台
- 附件用 AstrBot 的 `File`/`Image` 下载到 `inbox/`，把本地路径写进任务
- 产物识别：优先解析回复里的绝对路径（含反引号包裹），兜底取任务期间新增/修改的文件
